# PyQuest

A gamified Python foundations experience for absolute beginners. Learn Python by playing — no coding background required.

**Status:** in development.

## How to play

Once deployed, just open the live URL in any modern browser. The game runs entirely in the browser using Pyodide (real Python compiled to WebAssembly).

## Tech stack

- HTML, CSS, vanilla JavaScript — no build step
- Pyodide via CDN for in-browser Python execution
- CodeMirror 6 via CDN for the code editor
